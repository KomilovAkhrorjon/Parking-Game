# Parking Game – Unity Project

**Parking Game** is a simple car parking game developed using **Unity** as part of the *Visual Programming* module at **Westminster International University in Tashkent (WIUT)**. The goal of the game is to park the car in the designated area without hitting any obstacles.

---

## Project Summary

- **Course**: Visual Programming  
- **Institution**: WIUT  
- **Assignment Goal**: Build a basic interactive game using Unity and C#  
- **Engine**: Unity  
- **Level**: Single-level (as required by the assignment)  
- **Grade**: *50 out of 50*

---

## Game Features

-  **Parking Objective** – Park the car in the correct spot  
-  **Obstacle Avoidance** – Hitting any object ends the level  
-  **Keyboard Controls** – Drive using arrow or WASD keys  
-  **One Level Only** – Simple gameplay as per module requirements

---

## Tech Stack

- **Game Engine**: Unity  
- **Language**: C#  
- **IDE**: Unity Editor + Visual Studio

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/KomilovAkhrorjon/Parking-Game.git

2. Open the project in Unity Hub
3. Open the main scene from Assets/Scenes
4. Press Play to start the game in the editor
5. Or you can find TheBuild folder wich contains .exe build.

## Notes
- ** The project is focused on basic object movement, collision detection, and game flow **
- ** Designed to demonstrate understanding of event handling, physics, and UI feedback in Unity **
- ** No advanced game mechanics or multiple levels were implemented **
